# Kayavak Corrections

This repository collects issues and corrections for [kayavak.com](https://kayavak.com).

## Report an issue

[Open an issue](../../issues/new) and include:

- **Page:** the URL where you found the issue
- **What’s wrong:** describe the error or problem
- **Suggested correction:** include the corrected text or expected behavior, if known
- **Evidence:** add a screenshot or other helpful context

Please report one issue per ticket so each correction can be tracked separately.

## Scope

Use this repository for errors, outdated information, broken links, display problems, and other corrections needed on kayavak.com. It tracks reports; the website’s source code is maintained elsewhere.

Please don’t include passwords, private information, or other sensitive data in an issue.
